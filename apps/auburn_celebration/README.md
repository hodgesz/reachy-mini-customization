# Auburn Celebration

Private local app for Reachy Mini Control. Scaffolded with Pollen's official app assistant.

Uses the shared `reachy-mini-customization` package and plays the routine once when Start is clicked. Stop requests a smooth return to neutral. No account, web page, audio, or automatic startup behavior is required.

Install all three packages with `scripts/install_robot_apps.py` from the repository root.
