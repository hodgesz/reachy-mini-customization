# Auburn Celebration

Private local app for Reachy Mini Control. Scaffolded with Pollen's official app assistant.

Uses the shared `reachy-mini-customization` package and plays the complete bundled 1955 “War Eagle” recording through the robot's speaker while dancing. Stop ends the music and requests a smooth return to neutral. No account, web page, Internet connection, or automatic startup behavior is required. Music attribution and CC BY-NC-SA 4.0 source terms are included in the shared package.

Install all three packages with `scripts/install_robot_apps.py` from the repository root.
